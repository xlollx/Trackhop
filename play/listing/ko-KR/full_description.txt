여러 음악 서비스의 플레이리스트를 똑같이 유지하세요. 손으로 다시 만들 필요가 없어요.

- 원본 플레이리스트와 대상 플레이리스트를 고르거나, 같은 이름으로 앱이 만들게 하세요
- 원할 때 동기화하거나 예약하세요: 매시간, 6시간마다, 매일, 또는 원하는 요일에 매주
- 추가만, 삭제도 반영, 또는 두 플레이리스트 사이 양방향으로. 서비스가 허용하면 원본 순서를 유지해요
- 좋아요 표시한 곡, 저장한 앨범, 팔로우한 아티스트, 팟캐스트도 원본으로
- 같은 서비스의 여러 계정, 각각 따로 로그인
- 공개 플레이리스트 링크를 붙여 넣거나 다른 앱에서 공유해 내 보관함으로 동기화
- 동기화 전 미리 보기: 무엇이 추가되고 삭제될지 보고 확인
- 찾지 못한 곡은 직접 해결: 대상 서비스에서 검색해 맞는 곡을 고르면 앱이 기억해요
- 플레이리스트 생성기: 원하는 플레이리스트를 설명하면 내 AI(OpenAI, Anthropic, Google Gemini, 호환 서버, 또는 지원 기기의 온디바이스 AI)가 곡을 제안하고, 앱이 실제로 있는 곡인지 확인한 뒤에 만들어요. 기존 플레이리스트도 같은 방식으로 늘릴 수 있어요
- 플레이리스트 관리: 이름 변경, 삭제, 공개·비공개 전환, 제목·아티스트·앨범으로 곡 삭제, 중복 제거
- 파일: CSV, M3U, Apple Music/iTunes XML, JSON 가져오기와 내보내기. 모든 플레이리스트를 날짜별로 백업, 원하는 폴더에도 저장
- 내 색상과 스타일의 동기화 카드, 홈 화면 위젯과 바로가기
- 계정마다 연결 테스트, 동기화마다 결과 확인

Spotify, Apple Music, YouTube Music, TIDAL, Deezer, 개인 Navidrome/Subsonic·Jellyfin·Plex 서버, Last.fm, ListenBrainz, 그리고 파일과 함께 작동해요. 일부 커넥터는 앱에서 베타로 표시돼요. 잘 작동하지만 다른 커넥터보다 사용 경험이 적어요.

무료이며 구독, 인앱 구매, 광고가 없어요.
만들 계정도 없고 저희 서버도 없어요. 모든 것이 휴대폰에 남고, 액세스 토큰은 Android Keystore로 암호화되어 누구도 거치지 않아요. 각 서비스의 공식 페이지에서 로그인해요. Spotify, YouTube Music, TIDAL, Deezer는 내 이름으로 무료 키를 약 2분 만에 만들 수 있고, 앱이 단계별로 안내해요.

예약된 동기화는 서버 없이 휴대폰에서 실행돼요. 휴대폰이 꺼져 있거나 절전 기능이 앱을 막으면 다음 기회에 이어서 실행해요.

Trackhop은 Spotify, Apple, Google/YouTube, TIDAL, Deezer와 제휴 관계가 없어요. 서비스 이름은 각 소유자의 상표이며 호환성을 표시하기 위해서만 사용해요.
