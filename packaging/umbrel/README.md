# Trackhop's Umbrel app store

Add this store in umbrelOS: **App Store › ⋯ › Community App Stores**, paste
`https://github.com/xlollx/umbrel-apps` and open *Trackhop App Store*. Trackhop opens on port 8642,
behind Umbrel's own sign-in.

Trackhop is a beta: keep a copy of your data (*Tools › Backup & restore*). Guide:
<https://trackhop.org/guide/docker>.
