# Помогите добавить музыкальный сервис из вашей страны

Некоторые сервисы открываются только в одной стране или принимают только местный номер телефона
или банковскую карту: Яндекс Музыка, VK Музыка, NetEase Cloud Music, Pandora и многие другие.
Разработчик Trackhop не может в них войти, поэтому не видит, как их сайт общается со своими
серверами, а без этого коннектор написать нельзя.

Вы можете помочь. Вы всё равно пользуетесь сервисом: запишите, что делает его сайт, пока вы им
пользуетесь, и отправьте файл. Обычно этого достаточно, чтобы начать работу над коннектором.

## Какие сервисы мы ищем

Если вы пользуетесь одним из них, запись поможет:

- **Россия и соседние страны**: Яндекс Музыка, VK Музыка, Звук.
- **Китай**: NetEase Cloud Music (с аккаунтом: ваши плейлисты, добавление треков), QQ Music,
  Kugou, Kuwo.
- **Остальная Азия**: KKBOX, JOOX, LINE Music, AWA, Melon, Genie, Bugs, FLO, VIBE, Wynk, Hungama, Gaana.
- **Америка**: Pandora, iHeartRadio, SiriusXM, Claro Música.
- **Европа**: BBC Sounds.

Вашего сервиса нет в списке? Запись всё равно пригодится.

## Перед началом

- **Сначала войдите в аккаунт**, потом начинайте запись. Сам вход нам не нужен, а в нём больше
  всего личных данных.
- Используйте только свой аккаунт, никогда чужой.
- **Когда закончите, выйдите из аккаунта на сайте.** Это завершает сеанс, который видела запись.

## Способ 1: в приложении Trackhop (Android, рекомендуется)

В версии Trackhop с GitHub/F-Droid есть инструмент записи. Он сохраняет только обращения к
серверам самого сервиса и удаляет то, что позволило бы кому-то войти в ваш аккаунт (см.
[Что содержит файл](#что-содержит-файл)). В версиях из Play Store и AppGallery его нет.

1. *Настройки › О приложении*: нажмите на номер версии семь раз. Появятся инструменты записи.
2. *Настройки › Дополнительно › Захват сайта*: введите адрес сайта сервиса (например,
   `https://music.yandex.ru`) и нажмите **Открыть**. Настоящий сайт откроется внутри приложения.
3. Войдите в аккаунт, затем нажмите **Очистить**.
4. Выполните шаги ниже по порядку.
5. Нажмите **Поделиться** и отправьте файл, как описано в разделе [Как отправить](#как-отправить).
   Когда выходите с экрана, выберите *Удалить*; иначе телефон удалит файл через сутки.

Если файл почти пустой, сайт сервиса, возможно, обращается к серверам с другим именем:
используйте способ 2.

## Способ 2: в браузере на компьютере

Chrome, Edge или Firefox на компьютере:

1. Откройте сайт сервиса и войдите в аккаунт.
2. Нажмите **F12** (или правый клик, *Просмотреть код*) и откройте вкладку **Network** (Сеть).
   Отметьте *Preserve log* (Chrome) или *Persist logs* (Firefox).
3. Нажмите кнопку очистки (🚫), затем выполните шаги ниже по порядку.
4. Правый клик по любой строке списка, затем *Save all as HAR* (в Chrome выберите вариант
   *sanitized*, если он предлагается).
5. **Выйдите из аккаунта на сайте.** Файл из браузера может содержать ключи к вашему аккаунту,
   даже «sanitized»; выход из аккаунта делает их бесполезными. Затем отправьте файл, как описано ниже.

## Какие шаги выполнить

Делайте то, что позволяет сайт, медленно, по одному действию:

1. Откройте свои плейлисты (медиатеку).
2. Откройте один из своих плейлистов и прокрутите до конца.
3. Найдите песню через поиск.
4. Создайте тестовый плейлист.
5. Добавьте в него песню, затем удалите её.
6. Откройте любимые треки (избранное). Поставьте лайк песне, затем уберите его.
7. Переименуйте тестовый плейлист, затем удалите его.

Если есть ещё несколько минут, это тоже поможет:

- **Подпишитесь и отпишитесь**, по одному: на исполнителя, альбом, подкаст, чужой плейлист.
- **Измените тестовый плейлист** перед удалением: поменяйте обложку, описание и название,
  переключите его между публичным и приватным.

Шаг, который сайт не позволяет, — тоже полезная информация: напишите об этом.

## Как отправить

- **По электронной почте** на [xlollx@trackhop.org](mailto:xlollx@trackhop.org), с названием
  сервиса и вашей страной. Можно писать по-русски.
- **Никогда не прикладывайте запись к публичному issue на GitHub.** Можно открыть
  [issue](https://github.com/xlollx/Trackhop/issues/new/choose) и написать «могу записать X»:
  сам файл отправляется по почте.

## Что содержит файл

Адрес, метод, запрос и ответ каждого обращения, которое сайт сделал, пока вы выполняли шаги.
Сюда входят названия и треки ваших плейлистов, а также имя пользователя или номер аккаунта.

Инструмент записи в приложении удаляет то, что позволило бы действовать от вашего имени: cookie
никогда не записываются, заголовки входа (authorization, токены, сеансы, CSRF) заменяются их
длиной, а пароли, адреса почты, номера телефонов и токены доступа стираются в адресах и формах.
Файл из браузера удаляет меньше, поэтому так важно выйти из аккаунта после записи.

Файл читается один раз, чтобы понять, как работает сайт, и затем удаляется. Он никогда не
публикуется, а коннектор пишется по нему вручную.

## Что дальше

1. По записи видно, можно ли добавить сервис и как: полностью (чтение и запись плейлистов),
   только как источник или никак.
2. Если можно, коннектор появится в одной из следующих версий. Иногда нужна вторая запись для
   одного недостающего шага; вам напишут, какого именно.
3. Перед выпуском коннектора вас могут попросить проверить тестовую сборку на вашем аккаунте.

Сервис, добавленный так, работает для всех в вашей стране, а не только для вас.
