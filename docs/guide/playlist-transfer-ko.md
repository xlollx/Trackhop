# 플레이리스트를 다른 서비스로 무료로 옮기기

Trackhop은 플레이리스트와 좋아요 표시한 곡을 Spotify에서 YouTube Music, Apple Music, Amazon Music, TIDAL, Deezer로(반대로도) 복사하고, 원하면 **계속 동기화**합니다. 직접 실행하거나 일정 간격으로 실행할 수 있습니다. 무료 오픈 소스이며 Trackhop 계정도 곡 수 제한도 없습니다. 모든 것이 휴대폰이나 컴퓨터에서 실행됩니다.

## 사용 방법

1. Android에 Trackhop 설치([F-Droid](https://f-droid.org/packages/com.xlollx.songport/) 또는 [GitHub](https://github.com/xlollx/Trackhop/releases/latest)), 또는 컴퓨터에서는 [Trackhop Desktop](desktop)(Windows, macOS, Linux).
2. *계정 → 커넥터 추가*에서 두 서비스를 연결합니다. Spotify 빠른 연결은 평소 계정을 사용하며 키도 Premium도 필요 없습니다(사이트 버전과 F-Droid 버전).
3. 원본 플레이리스트와 대상을 고르고 미리보기를 확인한 뒤 실행합니다. 계속 같게 유지하려면 주기를 고르세요: 1시간마다, 6시간마다, 매일, 매주.

## 할 수 있는 것

- **모든 플레이리스트를 한 번에**, 곡 수 제한 없이 옮기기.
- **좋아요 표시한 곡**과 저장한 앨범도 옮기기.
- 찾지 못한 곡을 한 번의 탭으로 제안받아 확인.
- 플레이리스트 백업과 CSV·M3U 내보내기.
- 내 Navidrome, Jellyfin, Plex 서버도 사용.

## 정말 무료

유료 요금제 없음, 곡 수 제한 없음, 가입 없음. 로그인 정보는 기기에 암호화되어 저장되며 Trackhop 서버를 거치지 않습니다(서버가 없습니다).
