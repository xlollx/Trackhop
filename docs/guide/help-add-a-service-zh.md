# 帮忙把你所在国家的音乐服务加入 Trackhop

有些服务只在一个国家开放，或者只接受当地的手机号或银行卡：网易云音乐、QQ音乐、酷狗、
Yandex Music、Pandora 等等。Trackhop 的开发者无法登录这些服务，因此看不到它们的网站如何与
服务器通信，没有这些信息就无法编写连接器。

你可以帮忙。你本来就在用这个服务：在使用时记录它的网站做了什么，然后把文件发过来。
通常这就足够开始编写连接器了。

## 我们在找的服务

如果你在用下面的某个服务，你的抓取会很有帮助：

- **中国**：网易云音乐（登录账号后：你自己创建的歌单、添加歌曲）、QQ音乐、酷狗音乐、酷我音乐。
- **亚洲其他地区**：KKBOX、JOOX、LINE Music、AWA、Melon、Genie、Bugs、FLO、VIBE、Wynk、Hungama、Gaana。
- **俄罗斯及周边**：Yandex Music、VK Music、Zvuk。
- **美洲**：Pandora、iHeartRadio、SiriusXM、Claro Música。
- **欧洲**：BBC Sounds。

你的服务不在列表里？同样欢迎抓取。

## 开始之前

- **先登录**，再开始抓取。登录过程本身我们不需要，而它包含的个人信息最多。
- 只用你自己的账号，不要用别人的。
- **完成后退出网站的登录。** 这样抓取中出现的会话就失效了。

## 方法一：用 Trackhop 应用（Android，推荐）

GitHub/F-Droid 版的 Trackhop 带有抓取工具。它只保留发往该服务自己服务器的请求，并删除能让别人
使用你账号的内容（见[文件里有什么](#文件里有什么)）。Play 商店和华为应用市场（AppGallery）版本没有这个工具。

1. *设置 › 关于*：点击版本号七次，抓取工具就会出现。
2. *设置 › 高级 › 抓取网站流量*：输入服务的网址（例如 `https://music.163.com`），点 **打开**。
   真实的网站会在应用内打开。
3. 登录，然后点 **清除**。
4. 按顺序完成下面的步骤。
5. 点 **分享**，按[如何发送](#如何发送)里的方式发送文件。离开页面时选择 *删除*；
   否则手机会在一天后删除它。

如果分享出来的文件几乎是空的，说明这个网站可能在和其他名字的服务器通信：请用方法二。

## 方法二：用电脑浏览器

在电脑上用 Chrome、Edge 或 Firefox：

1. 打开服务的网站并登录。
2. 按 **F12**（或右键 › *检查*），打开 **Network**（网络）标签。勾选 *Preserve log*（保留日志，Chrome）
   或 *Persist logs*（持续日志，Firefox）。
3. 点清除按钮（🚫），然后按顺序完成下面的步骤。
4. 在列表中任意一行上右键，选择 *Save all as HAR*（全部另存为 HAR；Chrome 如果提供 *sanitized*
   选项，请选它）。
5. **退出网站的登录。** 浏览器导出的文件仍可能包含你账号的密钥，即使是 "sanitized" 版本；
   退出登录会让这些密钥失效。然后按下面的方式发送。

## 要做的步骤

在网站允许的范围内，慢慢地、一次做一步：

1. 打开你的歌单（音乐库）。
2. 打开你的一个歌单，滚动到底部。
3. 搜索一首歌。
4. 创建一个测试歌单。
5. 往里面添加一首歌，然后再删掉。
6. 打开你喜欢的音乐（收藏）。收藏一首歌，然后取消收藏。
7. 重命名测试歌单，然后删除它。

如果还有几分钟，这些也很有帮助：

- **关注和取消关注**，一次一个：一位歌手、一张专辑、一个播客、别人的歌单。
- 删除前**编辑测试歌单**：更换封面、简介和标题，并在公开和私密之间切换。

网站不允许的步骤也是有用的信息：请告诉我们。

## 如何发送

- **通过电子邮件**发送到 [xlollx@trackhop.org](mailto:xlollx@trackhop.org)，写上服务名称和你所在的国家。
  可以用中文写。
- **绝不要把抓取文件附在公开的 GitHub issue 里。** 你可以开一个
  [issue](https://github.com/xlollx/Trackhop/issues/new/choose) 说"我可以抓取 X"：文件本身通过邮件发送。

## 文件里有什么

你完成这些步骤时，网站发出的每个请求的地址、方法、请求内容和响应。其中包括你的歌单名称和歌曲，
以及你的用户名或账号编号。

应用的抓取工具会删除能让别人冒充你的内容：从不写入 cookie，登录相关的请求头（authorization、
token、会话、CSRF）只保留长度，地址和表单中的密码、邮箱、手机号和访问令牌会被清空。
浏览器导出的文件删除得更少，所以事后退出登录很重要。

文件只会被读取一次，用来了解网站如何工作，然后就会被删除。它不会被公开，连接器是根据它手工编写的。

## 接下来会怎样

1. 从抓取中可以看出这个服务能否加入、以什么方式：完整服务（读写你的歌单）、仅作为来源，或者不行。
2. 如果可以，连接器会在之后的某个版本中推出。有时需要为缺少的某一步再抓取一次；你会收到邮件，
   说明具体是哪一步。
3. 连接器发布前，可能会请你用自己的账号试用测试版。

这样加入的服务，你所在国家的所有人都能用，而不只是你。
