# 在不同音乐服务之间免费迁移歌单

Trackhop 可以把你的歌单和喜欢的歌曲从 Spotify 复制到 YouTube Music、Apple Music、Amazon Music、TIDAL 或 Deezer（反之亦可），并按需**保持同步**：手动运行或定时运行。免费开源，无需 Trackhop 账号，也没有歌曲数量限制：一切都在你的手机或电脑上运行。

## 如何使用

1. 在 Android 上安装 Trackhop（[F-Droid](https://f-droid.org/packages/com.xlollx.songport/) 或 [GitHub](https://github.com/xlollx/Trackhop/releases/latest)），或在电脑上使用 [Trackhop Desktop](desktop)（Windows、macOS、Linux）。
2. 在 *账号 → 添加连接器* 中连接两个服务。Spotify 的快速连接使用你的普通账号，无需密钥，也无需 Premium（网站版和 F-Droid 版）。
3. 选择源歌单和目标，查看预览后确认。若要保持一致，请选择频率：每小时、每 6 小时、每天或每周。

## 你可以做什么

- **一次迁移所有歌单**，没有歌曲数量限制。
- 带走**喜欢的歌曲**和收藏的专辑。
- 查看未找到的歌曲，一键获得建议。
- 备份歌单，导出为 CSV 或 M3U。
- 也可以使用你自己的 Navidrome、Jellyfin 或 Plex 服务器。

## 真正免费

没有付费方案，没有歌曲数量限制，无需注册。你的登录信息加密保存在设备上，从不经过 Trackhop 服务器（根本没有服务器）。
