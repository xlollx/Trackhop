# Un'alternativa gratuita a Soundiiz e TuneMyMusic

Soundiiz e TuneMyMusic vanno bene per uno spostamento una tantum, ma la sincronizzazione automatica e
le playlist lunghe sono a pagamento, e i tuoi accessi ai servizi passano dai loro server. Trackhop fa
le stesse cose **gratis**, senza limiti di brani, e tutto resta sui tuoi dispositivi.

| | Trackhop | Servizi di trasferimento online |
|---|---|---|
| Dove gira | Sul tuo telefono o computer | Sui loro server |
| Chi tiene i tuoi accessi | Solo il tuo dispositivo, cifrati | Il servizio |
| Account, abbonamento | Nessuno | Account; limiti nel piano gratuito |
| Sync programmata, rimozioni | Sì | Di solito a pagamento |
| Server personali (Navidrome, Jellyfin, Plex) | Sì | Raramente |
| Codice sorgente | Aperto (AGPL-3.0) | Chiuso |

## Come iniziare

1. Installa [Trackhop](https://github.com/xlollx/Trackhop/releases/latest) su Android (anche da
   [F-Droid](https://f-droid.org/packages/com.xlollx.songport/)) o [Trackhop Desktop](desktop) sul
   computer.
2. Collega i servizi che usi: Spotify, YouTube Music, Apple Music, Amazon Music, TIDAL, Deezer,
   Navidrome, Jellyfin, Plex.
3. Crea una sync, controlla l'anteprima e avviala. [Qui i passi nel dettaglio](trasferire-playlist).
